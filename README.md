# Jargon

Jargon 是一个按需加载的专业术语索引，帮助 LLM 把用户模糊的白话需求扩展成更具体、可执行的提示词。

## 核心结构

```text
根领域索引 → 领域/意图索引 → 术语包 → LLM 语义匹配 → 增强提示词
```

## 目录

- `index/root.json`：多级根领域索引
- `index/packages.json`：领域、意图和术语包索引
- `terms/`：术语列表与模糊词映射
- `skills/jargon/SKILL.md`：简化运行规则

术语包中的 `published` 表示可直接用于运行时；`draft` 表示草案，Agent 不应把草案术语当作确定事实。缺少覆盖时，可在用户允许后进行临时网络搜索。

## 贡献

新增领域时先补根索引，再增加术语包。每个术语至少包含：术语、白话解释、适用维度、收益和代价。不要提交密钥、令牌、个人路径或真实用户隐私。
